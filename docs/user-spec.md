# ユーザ仕様書（ユーザ視点）

作成日: 2026-02-14  
対象: Svara v0.1.0 相当

## 1. このアプリでできること（概要）

Svara は、タスクを「期限（いつまで）」中心に整理して運用する、シンプルなタスク管理アプリです。

- **Backlog（3カラム）**で、期限ありタスクを `Backlog / Doing / Waiting` に分けて管理できます
- **期限なし**画面で、期限が未設定のタスクを集中的に棚卸しできます
- **Done** 画面で、完了したタスクを時系列で振り返れます

## 2. 用語 / データ項目

### 2.1 タスク

タスクは次の情報を持ちます。

| 項目 | 説明 |
|---|---|
| タイトル | タスク名 |
| ステータス | `Backlog / Doing / Waiting / Done` |
| 開始日 | 作業開始日（Doingに移したタイミングで自動的に入ることがあります） |
| 期限 | 期限日（期限なしも可） |
| ノート | Markdownで書けるメモ |
| タグ | タスク分類用（複数付与可） |

### 2.2 ステータス

| ステータス | 意味 |
|---|---|
| Backlog | 実行可能だが未着手 |
| Doing | 着手中 |
| Waiting | 外部待ち / ブロック |
| Done | 完了 |

## 3. 画面一覧と目的

| 画面 | URL | 目的 |
|---|---|---|
| Backlog | `/` | **期限あり**タスクを、3カラムで運用するメイン画面 |
| 期限なし | `/no-due` | **期限なし**タスクを棚卸しし、期限設定やステータス整理を行う画面 |
| Done | `/done` | 完了したタスクを一覧で確認する画面 |

共通UI:

- 画面上部のナビゲーション（`Backlog / 期限なし / Done`）
- 右側の **タスク詳細パネル**（タスクをクリックすると表示）
- 右下の **トースト通知**（保存成功/失敗など）

## 4. Backlog画面（/）

### 4.1 表示されるタスク

- `Backlog / Doing / Waiting` の3カラムが表示されます
- **期限が設定されているタスク（期限あり）のみ**が表示されます
  - 期限なしタスクは、この画面には表示されません（`/no-due` で扱います）

### 4.2 並び順（自動）

各カラムのタスクは手動で並び替えできません。常に自動でソートされます。

1. 期限が近い順（昇順）
2. 更新が新しい順（降順）
3. ID順（昇順）

### 4.3 新規タスク作成

- 「＋ 新規タスク」でタスクを作成します
- 作成直後のタスクは、**期限が未設定**の状態で作成されます
  - Backlog画面に表示したい場合は、詳細パネルで期限を設定してください

### 4.4 ステータス変更（ドラッグ＆ドロップ）

- タスクカードをドラッグ＆ドロップして、カラム間でステータスを変更できます
- **期限なしのタスクは `Doing / Waiting` に移動できません**
  - 移動はキャンセルされ、通知と「期限を設定」導線が表示されます

### 4.5 タグフィルタ（OR検索）

- 画面上部にタグが表示され、複数選択で絞り込めます
- 条件は **OR**（選んだタグのいずれかを持つタスクを表示）
- フィルタはページをリロードすると解除されます

## 5. 期限なし画面（/no-due）

### 5.1 表示されるタスク

- **期限が未設定**かつ **未完了**のタスクが一覧表示されます

### 5.2 できる操作

- 期限の設定（行内の日付入力）
- ステータスの変更（行内のプルダウン）
  - **期限なしのまま `Doing / Waiting` には変更できません**
- タスクをクリックして詳細パネルを開く
- 「＋ 新規タスク」でタスクを作成する

## 6. Done画面（/done）

### 6.1 表示されるタスク

- `Done` のタスクのみが一覧表示されます
- 完了日時が新しい順に並びます

### 6.2 操作

- タスクをクリックして詳細パネルを開けます
- UI上は、**完了を「未完了」に戻す操作は提供しません**

## 7. タスク詳細パネル（右側）

タスクをクリックすると右側に詳細パネルが開き、次を確認・編集できます。

### 7.1 編集できる項目

- タイトル
- 開始日（※ Done のタスクは編集不可）
- 期限
- タグ（付与/解除、作成、削除）
- ノート（Markdown）

※ステータスは詳細パネルから変更しません（Backlogのドラッグ＆ドロップ、または期限なし画面のプルダウンで変更します）。

### 7.2 自動保存

- タイトル/ノートは入力後に自動保存されます（少し待つ、またはフォーカスを外す）
- 開始日/期限は変更確定（date入力の変更）で保存されます
- 保存に失敗した場合はエラー表示が出て、**再試行**できます

### 7.3 完了 / 削除

- 未完了タスクは「✅ 完了にする」で `Done` にできます（完了日時が記録されます）
- 「🗑️ 削除」は確認後にタスクを削除します

## 8. ノート機能（Markdown）

ノートは Markdown で記述でき、「✏️ 編集 / 👁️ プレビュー」を切り替えられます。

- よく使う記法のツールバー（太字/斜体/取り消し線、見出し、箇条書き、チェックリスト、リンク、コード、引用）
- `Tab` / `Shift+Tab` でインデント操作
- `Enter` でリストの自動継続（箇条書き・番号・引用・チェックリスト）
- プレビューでチェックリストをクリックして `[ ] / [x]` を切り替え
- 「↗ 拡大」でノート編集を大きなモーダルで表示

## 9. 期限の見え方

- 期限は日付として扱います（時刻の入力はしません）
- API/内部表現は ISO8601 datetime 文字列ですが、意味としては **JST の 00:00 固定**の日付として扱います
- タスクカードでは相対表示（例: 今日/明日/◯日後）になり、期限が近いものが把握しやすくなります
- 期限切れのタスクは強調表示されます

## 10. 制限事項（現状）

- ユーザー登録・ログインはありません（単一ユーザーのローカル運用を想定）
- 検索、アーカイブ、繰り返しタスク、リマインダー通知はありません
- Backlog各カラム内の手動並び替え（任意順の固定）はできません
