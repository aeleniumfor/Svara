# Note機能改善 仕様書

## 概要

タスクに紐づくNote（ノート）機能を、Markdownで**書きやすく・見やすく**改善する。  
以下4つの機能を追加・改修する。

| # | 機能 | 優先度 |
|---|---|---|
| 1 | 編集ツールバー（Markdownショートカット） | ★★★ |
| 2 | Tabキーインデント + Enterリスト自動継続 | ★★★ |
| 3 | GFMチェックリスト対応（表示 + クリックトグル） | ★★☆ |
| 4 | 拡大表示モード（モーダル） | ★★★ |

---

## 1. 編集ツールバー

### 1.1 表示位置

- 編集モード時に `<textarea>` の上部に **1行** で表示する。
- サイドパネル内・拡大モーダル内の両方で共通のツールバーを使用する。
- プレビューモード時はツールバーを非表示にする。

### 1.2 ボタン一覧

ボタンはグループ分けし、グループ間は縦の区切り線（`1px solid border`）で視覚的に分離する。

| グループ | ボタン | 表示ラベル | 動作 | ショートカット |
|---|---|---|---|---|
| テキスト装飾 | 太字 | **B** | `**text**` で囲む | `Ctrl+B` |
| | 斜体 | *I* | `*text*` で囲む | `Ctrl+I` |
| | 取り消し線 | ~~S~~ | `~~text~~` で囲む | — |
| 構造 | 見出し | H▾ | 行頭に `## ` 挿入（サイクル: `#` → `##` → `###` → 解除） | — |
| | 箇条書き | ≡ | 行頭に `- ` 挿入 | — |
| | チェックリスト | ☐ | 行頭に `- [ ] ` 挿入 | — |
| 挿入 | リンク | 🔗 | `[text](url)` を挿入 | `Ctrl+K` |
| | コード | `<>` | インライン: `` `text` ``、複数行選択時: コードブロック（` ``` `） | — |
| | 引用 | `>` | 行頭に `> ` 挿入 | — |

### 1.3 動作ルール

#### テキスト選択ありの場合

| 種類 | 動作 |
|---|---|
| 囲み系（B, I, S, コード） | 選択範囲を該当Markdown記法で囲む |
| 行頭系（H, ≡, ☐, >） | 選択範囲を含む行の先頭に記法を挿入 |
| リンク | `[選択テキスト](url)` を挿入し、`url` 部分を選択状態にする |

#### テキスト選択なしの場合

| 種類 | 動作 |
|---|---|
| 囲み系（B, I, S, コード） | プレースホルダーテキストを挿入して選択状態にする（例: `**太字テキスト**` → 「太字テキスト」が選択状態） |
| 行頭系（H, ≡, ☐, >） | カーソルのある行の先頭に記法を挿入 |
| リンク | `[リンクテキスト](url)` を挿入し、「リンクテキスト」を選択状態にする |

#### トグル動作（囲み系: B, I, S）

- カーソル位置または選択範囲が既に該当記法で囲まれている場合、記法を**解除**する。

### 1.4 スタイル

| 項目 | 値 |
|---|---|
| ボタンサイズ | `28px × 28px` |
| フォント | `font-weight: 600`、`font-size: 12px` |
| 通常時の色 | `--color-text-secondary` |
| ホバー時 | `background: --color-border-light` |
| ツールバー背景 | `--color-border-light`（既存のモード切替バーと視覚的に統合） |
| アイコンスタイル | テキスト/記号ベース（SVGや絵文字は使わない） |

## 2. Tabキーインデント + Enterリスト自動継続

### 2.1 Tab / Shift+Tab

`<textarea>` 内で `Tab` / `Shift+Tab` のデフォルト動作（フォーカス移動）を**抑止**し、インデント操作に置き換える。

| 操作 | 選択なし | 行選択あり |
|---|---|---|
| `Tab` | カーソル位置に **4スペース** を挿入 | 選択範囲に含まれる全行の先頭に4スペースを追加 |
| `Shift+Tab` | カーソル行の先頭から最大4スペースを削除 | 選択範囲に含まれる全行の先頭から最大4スペースを削除 |

- インデント幅: **4スペース**（固定）

### 2.2 Enterによるリスト自動継続

`Enter` キー押下時、カーソルのある行がリスト・引用の書式に一致する場合、次の行に同じ書式のプレフィックスを自動挿入する。

#### 継続ルール

| 現在の行のパターン | 次の行に自動挿入されるもの |
|---|---|
| `- テキスト` | `- ` |
| `- [ ] テキスト` | `- [ ] ` |
| `- [x] テキスト` | `- [ ] `（新しい項目は常に未チェック） |
| `N. テキスト`（番号リスト） | `N+1. `（番号を自動インクリメント） |
| `> テキスト` | `> ` |

#### 終了ルール

| 現在の行のパターン | Enterの動作 |
|---|---|
| `- ` （プレフィックスのみ、テキストなし） | プレフィックスを削除して空行にする（リスト終了） |
| `- [ ] ` （プレフィックスのみ） | 同上 |
| `- [x] ` （プレフィックスのみ） | 同上 |
| `N. ` （プレフィックスのみ） | 同上 |
| `> ` （プレフィックスのみ） | 同上 |

#### インデント保持

- 現在の行にインデント（先頭スペース）がある場合、次の行にも同じインデントを引き継ぐ。
  - 例: `    - アイテム` → Enter → `    - `

## 3. GFMチェックリスト対応

### 3.1 プレビュー表示

| Markdown | プレビュー表示 |
|---|---|
| `- [ ] テキスト` | ☐ テキスト（未チェックのチェックボックス） |
| `- [x] テキスト` | ☑ テキスト（チェック済みのチェックボックス） |

### 3.2 スタイル

| 項目 | 値 |
|---|---|
| リストスタイル | `list-style: none`（`•` マーカーを非表示） |
| チェックボックスの色 | `accent-color: var(--color-primary)` |
| チェック済みテキスト | `text-decoration: line-through; opacity: 0.6` |
| カーソル | チェックボックス部分のみ `cursor: pointer` |

### 3.3 クリックトグル

プレビューモードにおいて、チェックボックスをクリックすることで `[ ]` ⇔ `[x]` を切り替えられる。

#### 実装方針

1. `marked` のカスタムレンダラーで、各チェックリスト項目の `<input type="checkbox">` に `data-checkbox-index="{n}"` 属性を付与する（`n` はノート内のチェックリスト出現順の通し番号、0始まり）。
2. プレビュー領域に `click` イベントハンドラを設置する。
3. クリックされた要素が `input[type="checkbox"][data-checkbox-index]` の場合：
   - `data-checkbox-index` から対象のチェックリスト項目を特定する。
   - 元のMarkdownテキスト内で該当箇所の `[ ]` → `[x]`、または `[x]` → `[ ]` に書き換える。
   - `value` を更新する。
   - `onsave()` を呼び出して自動保存をトリガーする。

## 4. 拡大表示モード（モーダル）

### 4.1 起動・終了

| 項目 | 仕様 |
|---|---|
| 起動 | NoteEditorのツールバー右端に「↗ 拡大」ボタンを配置。クリックでモーダルを開く |
| 閉じ方（3つ） | ① モーダルヘッダーの `×` ボタン ② `Esc` キー ③ 背景オーバーレイのクリック |

### 4.2 モーダルUI

```
┌────────────────────────────────────────────────────────┐
│ 背景オーバーレイ (rgba(0,0,0,0.5))                       │
│                                                        │
│   ┌──────────────────────────────────────────────┐     │
│   │  📝 ノート - {タスクタイトル}        [× 閉じる] │     │
│   ├──────────────────────────────────────────────┤     │
│   │  [✏️ 編集]  [👁️ プレビュー]          [↙ 縮小] │     │
│   │  [B] [I] [S] │ [H▾] [≡] [☐] │ [🔗] [<>] [>] │     │
│   ├──────────────────────────────────────────────┤     │
│   │                                              │     │
│   │           textarea / プレビュー                │     │
│   │           (高さ: 残り全領域)                   │     │
│   │                                              │     │
│   └──────────────────────────────────────────────┘     │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 4.3 レイアウト仕様

| 項目 | 値 |
|---|---|
| モーダルサイズ | `width: 90vw; max-width: 1200px; height: 80vh` |
| 中央配置 | `position: fixed; top: 50%; left: 50%; transform: translate(-50%, -50%)` |
| z-index | `1000`（ナビバー `100` の上） |
| 背景オーバーレイ | `rgba(0, 0, 0, 0.5)` |
| 角丸 | `var(--radius-lg)` (`12px`) |
| 影 | `var(--shadow-lg)` |

### 4.4 モーダルヘッダー

| 項目 | 値 |
|---|---|
| 表示内容 | `📝 ノート - {タスクタイトル}` |
| タイトルの切り詰め | 長い場合は `text-overflow: ellipsis` で省略 |
| 閉じるボタン | `×` アイコン、右端に配置 |

### 4.5 モード切り替え

- サイドパネルと同じ「✏️ 編集 / 👁️ プレビュー」の**タブ切り替え**方式。
- 拡大モーダル内のモード切替とサイドパネルのモード切替は**独立**（モーダルを開いた時はデフォルトで編集モード）。

### 4.6 データ連動

| 項目 | 仕様 |
|---|---|
| 編集内容の同期 | `value` を `bind` でサイドパネルと共有。モーダル内の編集がリアルタイムでサイドパネルに反映される |
| 自動保存 | サイドパネルと同じ `onsave` コールバックを使用 |
| モーダルを閉じた時 | 未保存の変更がある場合は即時保存を実行 |

### 4.7 アニメーション

| 項目 | 値 |
|---|---|
| 開く時 | `opacity: 0 → 1` + `transform: scale(0.95) → scale(1)`、`200ms ease` |
| 閉じる時 | 即座に非表示（アニメーションなし） |

### 4.8 アクセシビリティ

- モーダルが開いている間、背景のスクロールを無効化する（`body` に `overflow: hidden`）。
- モーダルが開いたら、textarea（編集モード時）またはプレビュー領域にフォーカスを移す。
- `Esc` キーでモーダルを閉じる。
